# 미궁 라비린스 리소스팩

서버가 접속한 사람에게 보내는 리소스팩 파일입니다. 서버가 직접 보내지 못할 때 플러그인이 `pack-host/` 의 같은 팩을 대신 보냅니다.

파일 이름 뒤 8글자는 SHA-1 앞 8글자입니다. 서버팩 사용 조건은 서버팩 안의 LICENSE 를 따릅니다.

## 루네

같은 자리(`pack-host/`)에 루네 서버팩의 리소스팩 사본 `rune-pack-<8글자>.zip` 도 함께 둡니다. 루네 플러그인이 playit 같은 터널로 들어와 서버에서 팩을 직접 못 받은 친구에게 이 사본을 한 번 더 보냅니다. 파일 이름 뒤 8글자는 SHA-1 앞 8글자이고, 판마다 새 사본을 더 올립니다.
